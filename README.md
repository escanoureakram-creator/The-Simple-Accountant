# تطبيق محاسبة SCF (النظام المحاسبي المالي الجزائري)

تطبيق ويب متكامل ومخصص للطلبة، الأساتذة، والمحاسبين لتطبيق وإدارة **النظام المحاسبي المالي الجزائري (SCF)** بكل سهولة واحترافية من الهاتف أو الكمبيوتر.

## 🚀 الميزات الرئيسية:
* **دفتر اليومية**: تسجيل القيود المحاسبية مع التدقيق التلقائي لتوازن المدين والدائن والمدونة المحاسبية.
* **دفتر الأستاذ**: عرض حركة كل حساب وتتبع الأرصدة تفصيلياً.
* **حسابات T (الترصيد)**: ترصيد الحسابات وعرض الأرصدة المدينة والدائنة بصرياً.
* **ميزان المراجعة**: إظهار المجاميع والأرصدة والتأكد من توازن الميزان.
* **الميزانية (Bilan)**: إعداد الأصول والخصوم تلقائياً.
* **جداول النتائج**: حسابات النتائج حسب الطبيعة وحسب الوظيفة.
* **مسح الفواتير (OCR)**: قراءة الفواتير واقتراح الحسابات المحاسبية المناسبة.
* **النسخ الاحتياطي**: ميزة تصدير واستيراد البيانات (JSON) لحماية وتأمين بياناتك المحاسبية.
* **العمل بدون إنترنت**: دعم التثبيت كتطبيق هاتف (PWA).
